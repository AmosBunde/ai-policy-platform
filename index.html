The Platform

From raw regulation to decisions

Every capability an enterprise compliance function needs to stay ahead of fast-moving AI policy — in one event-driven platform.

Global ingestion

Continuously crawls regulatory documents, news, and legal updates from RSS feeds, APIs, and uploads — parsed and normalized by Celery workers.

LangGraph agent analysis

A multi-agent pipeline summarizes documents, extracts key policy changes, classifies domains, and drafts responses — with confidence scoring and token tracking.

Impact ranking

Ranks each regulatory change by region and product category, with urgency levels and affected-entity extraction so teams triage what matters first.

Compliance reports

Generates polished PDF and DOCX compliance reports from templates, with status tracking from draft through review to delivery.

Hybrid search

Elasticsearch full-text search combined with pgvector semantic similarity, so both exact citations and conceptual queries find the right clause.

Watch rules & alerts

Real-time dashboards track regulatory risk, while configurable watch rules deliver alerts by email, Slack, and webhooks the moment policy shifts.

AI Pipeline

How a regulation becomes an answer

Each document flows through a typed LangGraph state machine — every stage adds structure, and every output carries a confidence score.

Summarize

Long legal texts are chunked and distilled into executive summaries with key changes extracted verbatim.

Classify

Documents are tagged across policy domains — privacy, safety, IP, antitrust, export control, transparency, liability, and sector-specific rules.

Rank impact

Impact scores by region and product category, plus urgency level, effective dates, and affected entities.

Draft response

A compliance-ready draft response is generated for review — never auto-sent, always human-approved.

Security & Operations

Built to pass your security review

Defense-in-depth by default: a minimal public surface, authenticated service-to-service calls, and CI that blocks insecure changes before they merge.

  • Zero-trust network postureOnly the gateway (dev) or Caddy TLS proxy (prod) is exposed; all services and datastores are internal-only.
  • JWT auth, RBAC & internal service tokensRole-based access at the edge and authenticated service-to-service calls; secrets are required at deploy time with no insecure fallbacks.
  • Security scanning in CIBandit (blocking at medium+), Trivy vulnerability/secret scans with SARIF upload, and npm audit — on every PR and weekly.
  • Gated production deploysGitHub Actions builds to GHCR, scans images, then requires an approved environment gate before Helm deploys to Kubernetes.
  • Full observabilityPrometheus metrics, Grafana dashboards, and structured JSON logging with request-ID propagation across every service.
  • Tested at every layerUnit (pytest, vitest), integration via Docker Compose, end-to-end with Playwright, and load testing with Locust.

Quickstart

Running in five minutes

Docker Desktop, Node 20, and Python 3.11 are all you need.

  1. Clone & configure. Copy .env.example — it documents every variable and how to generate secrets.
  2. Start the stack. One compose command brings up the gateway, all six services, and infrastructure.
  3. Migrate & seed. make migrate && make seed prepares the database with sample data.
  4. Open the dashboard. Vite dev server at localhost:3000, API docs at localhost:8000/docs.
quickstart.sh
$ git clone https://github.com/AmosBunde/ai-policy-platform.git
$ cd ai-policy-platform
$ cp .env.example .env

$ docker compose up --build -d
$ make migrate && make seed

$ cd frontend && npm install && npm run dev

# Dashboard  → http://localhost:3000
# API + docs → http://localhost:8000/docs
